# Min and Max

## Problem Description
* **`min`**: Returns the minimum value along a given axis (defaults to `None` for all dimensions).
* **`max`**: Returns the maximum value along a given axis (defaults to `None` for all dimensions).


## Task
You are given a 2-D array with dimensions \(N \times M\). Your task is to perform the `min` function over axis `1` and then find the `max` of that result.
