# HackerRank: Sum and Prod

This repository contains the Python 3 solution for the HackerRank NumPy challenge **Sum and Prod**.

## Problem Statement

### **Task**
You are given a 2-D array with dimensions **N x M**.
1. Your first task is to perform the **sum** tool over axis `0`.
2. Your second task is to find the **product** of that resultant array.
