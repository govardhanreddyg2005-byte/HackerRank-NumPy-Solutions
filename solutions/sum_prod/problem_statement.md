# HackerRank: Sum and Prod

This repository contains the Python 3 solution for the HackerRank NumPy challenge **Sum and Prod**.

## Problem Statement

### **Task**
You are given a 2-D array with dimensions **N x M**.
1. Your first task is to perform the **sum** tool over axis `0`.
2. Your second task is to find the **product** of that resultant array.

### **Input Format**
* The first line contains space-separated integers **N** and **M**.
* The next **N** lines contain **M** space-separated integers.

### **Output Format**
* Compute the sum along axis `0`. Then, print the product of that sum.

### **Sample Input**
```text
2 2
1 2
3 4
```

### **Sample Output**
```text
24
```

### **Explanation**
* The sum along axis `0` is:  
  `[1+3, 2+4] = [4, 6]`
* The product of this resultant array is:  
  `4 * 6 = 24`
