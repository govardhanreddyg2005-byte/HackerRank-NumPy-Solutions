## Problem Statement

### identity
The identity tool returns an identity array. An identity array is a square matrix with all the main diagonal elements as 1 and the rest as 0.

```python
import numpy
print(numpy.identity(3)) #3 is the rows and columns

# Output :
# [[ 1.  0.  0.]
#  [ 0.  1.  0.]
#  [ 0.  0.  1.]]
```
